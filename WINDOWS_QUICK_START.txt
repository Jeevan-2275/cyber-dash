CYBER DASH - WINDOWS QUICK START
================================================================================

STEP 1: Extract ZIP
  unzip cyber-dash-complete.zip
  cd cyber-dash

STEP 2: Install Dependencies
  pnpm install

STEP 3: Start Dev Server
  pnpm run dev:metro

STEP 4: Test on Phone
  - Open Expo Go app on your phone
  - Scan QR code shown in terminal

AVAILABLE COMMANDS
================================================================================

pnpm install              Install dependencies
pnpm run dev:metro        Start Expo dev server (Android)
pnpm run dev:server       Start backend server (separate terminal)
pnpm run dev              Start both (requires 2 terminals)
pnpm run android          Direct Android command
pnpm run ios              Direct iOS command (Mac only)
pnpm check                TypeScript type checking
pnpm test                 Run tests
pnpm format               Format code
pnpm lint                 Lint code

================================================================================
TROUBLESHOOTING
================================================================================

ERROR: "The directory name is invalid"
  FIXED! Updated scripts for Windows compatibility.
  If still occurs: Delete node_modules, run pnpm install

ERROR: "expo: command not found"
  Run: npm install -g expo-cli

ERROR: "Android emulator not found"
  Open Android Studio → Tools → Device Manager → Create emulator

ERROR: "Cannot find module"
  Run: pnpm install --force

ERROR: "Expo Go won't connect"
  - Phone and PC must be on SAME WiFi
  - Restart Expo Go app
  - Run: pnpm run dev:metro again

ERROR: "Port 8081 already in use"
  Run: set EXPO_PORT=8082 && pnpm run dev:metro

================================================================================
BUILDING FOR APP STORES
================================================================================

1. Install EAS CLI:
   npm install -g eas-cli

2. Login to Expo:
   eas login

3. Build for Android:
   eas build --platform android

4. Build for iOS (Mac only):
   eas build --platform ios
